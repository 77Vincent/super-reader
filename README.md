# Super Reader

一个面向中文长文本的 Chrome 视觉分块阅读扩展。它使用本地 CNN 边界模型为每个相邻汉字间隙评分，仅采用高置信度预测，并用“有下划线 / 无下划线”交替出现的方式帮助视线定位。

## 功能

- 工具栏弹窗一键开启或关闭，关闭后恢复原网页文本
- 先按逗号、句号、分号、顿号、冒号、换行和成对双引号建立硬边界
- 模型只在每个不含断句标点的小句内部，递归为所有相邻汉字间隙评分
- 最高位置的 softmax 概率必须超过固定阈值 0.6 才会切分
- `Intl.Segmenter` 仅作为保护：预测落入一个词内部时放弃当前切分
- 没有目标分块长度，分段结果由标点边界和模型预测共同决定
- 非中文字符不进入模型且不添加下划线，原文保持不变
- 默认使用与文字同色的 3px 实线下划线，与普通区块交替；只覆盖文字，不覆盖标点或空白
- 自动处理无限滚动、单页应用等动态加入的正文
- 跳过代码、表单、按钮、可编辑区域和隐藏内容
- 所有处理均在浏览器本地完成，不收集或上传网页内容

运行时没有针对“的、地、得”或任何具体词组的手写规则。字符词表仅用于
查找训练得到的 embedding；小句内部的边界只由模型置信度和分词器词内保护共同决定。

## 本地安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 打开一个普通网页，点击工具栏中的 Super Reader 图标并开启。

如果网页在安装扩展前就已经打开，首次点击弹窗时扩展会尝试自动注入；Chrome 内部页面（如 `chrome://`）不允许扩展修改。

## 交互演示

直接用浏览器打开 [`demo.html`](demo.html)，即可体验文本输入和开关效果。演示页与扩展共用同一套分块算法。

## 开发与测试

浏览器推理后端没有第三方运行时依赖。分块算法测试使用 Node.js 自带测试框架：

```bash
npm test
```

边界模型的端到端小规模训练实验位于 [`training/`](training/README.md)，可运行：

```bash
npm run smoke:model
```

训练结束后，将最佳 checkpoint 导出为扩展与演示页共用的静态浏览器模型：

```bash
npm run model:export
```

修改扩展代码后，在 `chrome://extensions/` 中点击扩展卡片上的刷新按钮，再刷新要测试的网页。

## 文件结构

```text
manifest.json        Chrome Manifest V3 配置
src/boundary-model-data.js  浏览器端模型权重与字符表
src/model-backend.js        无依赖 CNN 推理后端
src/chunker.js              标点分句、递归模型切分与视觉分块
src/content.js       页面文本处理、恢复与动态内容监听
src/content.css      下划线视觉样式
src/background.js    默认设置、快捷键与工具栏状态
popup/               工具栏弹窗
test/                分块算法测试
```

快捷键 `Alt+Shift+R`（macOS 为 `Option+Shift+R`）可切换全局开关，也可以在 `chrome://extensions/shortcuts` 中修改。
