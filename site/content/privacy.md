好读是一款中文阅读辅助浏览器扩展，在网页长句中添加分隔线。本文说明当前版本如何处理信息，以及产品网站的相关行为。

## 网页内容在本地处理

开启好读后，扩展读取当前页面可视区域内符合条件的中文文本节点，并使用随扩展打包的神经网络在本机浏览器中计算切分位置。跨越可视区域的文本节点会作为完整节点处理。

用于推理的文本会在扩展的页面脚本、后台及本地推理进程之间传递，但不会发送给开发者、外部服务器或第三方 AI 服务。扩展不上传网页正文、网页地址或浏览历史，不使用网页内容训练模型，也不包含广告、分析统计或远程代码加载。

## 本地存储

扩展使用浏览器的本地扩展存储保存开启或关闭的设置。原文、推理结果及页面处理记录仅用于当前运行过程，不写入持久存储。扩展不要求注册账号，不使用浏览器同步存储。

关闭扩展会移除当前页面的阅读标记；后台页面会在下次切换到该页面时应用关闭状态。卸载扩展会移除扩展自身的本地设置。

## 权限用途

- **网站访问权限**：在开启状态下，为用户访问的 HTTP 和 HTTPS 网页提供阅读辅助，不需要对每个网站重复手动启用。浏览器的受限页面不能处理。
- **本地文件访问权限**：仅在用户另外打开“允许访问文件网址”后，支持对本地 HTML 页面进行相同的本地处理。
- **scripting**：向符合条件的页面插入阅读脚本和分隔线样式。
- **offscreen**：在浏览器的隐藏扩展页面中运行本地 Worker，多个网页共享同一份模型。
- **storage**：在本机保存开关状态。

## 产品网站

网站中的示例和分隔线为静态演示，不运行扩展模型，也不读取其他网页。网站不包含项目自行添加的访问统计或广告脚本；明暗主题偏好保存在浏览器本地。

访问网站仍需要向静态托管服务发送正常的网页请求。托管服务可能按照其政策记录 IP 地址、请求时间和浏览器信息等访问日志；这与扩展在本地处理正文是两个独立过程。通过网站跳转到 GitHub 或浏览器商店后，适用对应服务的隐私政策。
