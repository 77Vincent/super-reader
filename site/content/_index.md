- **直接在网页上使用。** 打开扩展后，在当前网页中查看分块标记。
- **保留原文。** 为阅读增加视觉提示，不改写文章内容。
- **本地运行。** 神经网络在浏览器中完成切分计算。
- **随时开关。** 点击工具栏图标或使用快捷键，恢复自己习惯的阅读方式。

## 如何使用 {#usage}

1. 在 Chrome 中安装 Super Reader，将扩展固定到工具栏。
2. 打开包含中文正文的网页，点击扩展图标开启切分阅读。
3. 再次点击图标即可关闭。开关状态会保存在本地。

也可以使用快捷键：macOS 为 **Shift + Option + R**，其他系统为 **Shift + Alt + R**。在 Chrome 的扩展程序快捷键设置中可以修改它。

## 常见问题 {#faq}

### 每句话都会被切分吗？

不会。切分阅读主要处理较长的句子，模型对候选位置有足够把握时才添加标记。不同文本的切分数量可能不同。

### 可以用于哪些内容？

可以在 Chrome 浏览的中文文章、博客和其他网页正文中使用。浏览器的内部页面等受限制页面无法运行扩展。

### 它会把文章改写成更短的句子吗？

不会。切分阅读添加的是视觉分隔标记，原有文字和标点保持不变。
